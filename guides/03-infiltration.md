# 🏭 滲透與工作站篇：3.0 的新玩法

3.0 版之後，每座城鎮多了一個**「前往」**按鈕。點下去就進入城內，可以**建設工作站**收素材、**拜訪角色**，同時累積該城的**滲透度**——而滲透度會直接回頭影響你所屬陣營在那座城的**戰力加成**。

這是目前最容易被新手忽略、但長期收益最高的系統：刷地是拿一次性的獎勵，滲透是拿**持續性的加成**。

> 💡 站上的[城鎮資訊](cities.html)頁面點進任一城市，就能看到該城的地點清單與各陣營滲透佔比。

---

## 1. 滲透度是什麼

每座城市都有一份**陣營滲透佔比**（各陣營瓜分 100%）。你在城內的每一次行動——建工作站、拜訪、探索——都會替你的陣營累積點數，佔比越高，**你的陣營在該城的戰力加成越高**。

從目前的資料快照可以看到全局態勢：

| 指標 | 數值 |
|------|------|
| 單一陣營壟斷的城市 | 113 座 |
| 兩個以上陣營角逐的城市 | 155 座 |
| 最多同時有幾個陣營插旗 | 9 個（單一城市）|

**九陣營的滲透總量分布相當平均**（各佔 7%~14%），代表這個系統目前還沒有被任何一方壟斷——**現在進場仍然來得及**。

| 陣營 | 滲透佔比 |
|------|---------|
| 自由勢力 | 13.6% |
| 臺灣 | 13.3% |
| 紅軍 | 13.1% |
| 藏國 | 11.7% |
| 蒙古 | 11.5% |
| 哈薩克 | 10.6% |
| 維吾爾 | 9.6% |
| 滿洲 | 9.2% |
| 香港 | 7.4% |

### 滲透度怎麼換算成戰力

**滲透比例會直接加進距離衰減係數裡**，跟進場前的路線扣血相抵：

```
進場戰力 = 國策加成 × ( 距離衰減 + 滲透比例 ) × 原始戰力
```

舉例：滲透度 55%、距離目標城 3 格鐵路（每格 −5%，共 −15% → 衰減係數 0.85）：

```
0.85 + 0.55 = 1.40   →  進場戰力是原始戰力的 1.4 倍（再乘國策加成）
```

**這就是滲透系統真正的價值所在。** 對照基礎篇的路線消耗表：

| 路線 | 距離衰減係數 | 滲透 0% | 滲透 55% |
|------|:-----------:|:------:|:-------:|
| 鐵路 ×1（−5%） | 0.95 | 0.95 | **1.50** |
| 鐵路 ×3（−15%） | 0.85 | 0.85 | **1.40** |
| 水/土/空路（−50%） | 0.50 | 0.50 | **1.05** |

**走水土空路本來要砍半戰力，滲透度拉起來之後反而不虧。** 這讓原本因為距離太遠而放棄的城市重新變成可打——對進攻範圍的影響比戰力本身更大。
### 個人滲透榜

每座城市都有一份個人滲透排行（前三名會顯示在城內）。目前資料中的分布：中位數約 **16 點**，最高紀錄 **352 點**。

**這代表冷門城市的榜首非常好搶**——十幾點就能上榜。與其去熱門城市跟人硬拚，不如挑幾座沒人經營的城市長期佔著。

> 🏆 **當上某座城的榜首，你所有編隊戰力 +200**，而且這 200 可以再吃國策加成。
>
> 參照 [⚡ 戰力與養成篇] 的換算：滿等 SSR 裝保定式也才 424 戰力，**一個榜首等於半隻滿等主力**。而中位數只要 16 點就能搶到——這是全遊戲投報率最高的一件事，新手務必去搶幾座冷門城。

## 2. 工作站

工作站是城內的**素材產出設施**。目前全圖共 **653 個工作站點位**，分成 5 種類型，每種產出固定素材：

| 工作站 | 產出素材 | 全圖點位數 | 備註 |
|--------|---------|:---------:|------|
| 宗教型 | 傳單 | 164 | 名稱隨信仰改變，見下方 |
| 性產業 | 話術 | 152 | |
| 藥物 | 線報 | 136 | |
| 博弈 | 信用 | 101 | |
| 走私 | 汽油 | 99 | |

**宗教型工作站佔全部點位的四分之一**（164 個）。它**沒有固定名稱**——會依照你個人主頁擺放的角色所信仰的宗教而改變顯示名稱（例如藏傳佛教角色會顯示成「扎倉」）。功能都一樣，統一理解為「宗教型工作站」即可。

> 📌 **待確認**：工作站產出的「**話術**」不是職業經驗素材，而是**羈絆素材**（見下方角色拜訪一節）。它的實際數值待補。

### 點位分布：城市不是平均的

每座城市的工作站點位數差很多：

| 點位數 | 城市數 |
|:------:|:------:|
| 1 個 | 117 座 |
| 2 個 | 41 座 |
| 3 個 | 38 座 |
| 4 個 | 21 座 |
| 5 個 | 25 座 |
| 6~8 個 | 26 座 |

**近半數城市只有 1 個點位**，而少數城市有 6~8 個。規劃滲透路線時，優先找**點位多又沒人經營**的城市——一趟能建的站越多，效率越高。

## 3. 工作站升級公式

工作站**等級沒有上限**，但**一個帳號最多只能持有 20 座**。設目前等級為 **L**：

### 每日產量

| 條件 | 產量 |
|------|------|
| L < 10 | `2^L` |
| L ≥ 10 | `1024 × (L − 9)` |

**10 級是分水嶺**：10 級以前每升一級產量翻倍，10 級之後改成線性成長。

| 等級 | 每日產量 | 備註 |
|:----:|--------:|------|
| 1 | 2 | |
| 5 | 32 | |
| 9 | 512 | 指數段最後一級 |
| 10 | 1,024 | 換成線性 |
| 15 | 6,144 | |
| 20 | 11,264 | |

### 升級消耗（動員力）

| 條件 | 動員力 |
|------|-------|
| L < 10 | `100,000 × 2^L` |
| L ≥ 10 | 固定 `102,400,000` |

**同國工作站再乘 0.8**（打八折）。

### 升級時間

| 條件 | 基礎時間 |
|------|---------|
| L < 10 | `10 × 2^L` 分鐘 |
| L ≥ 10 | 固定 `10,240` 分鐘 |

再乘上一個**戰力係數**：

```
(7000 − min(編隊戰力, 7000)) / 7000
```

### ⚡ 這條戰力係數是整套系統最關鍵的設計

**你的編隊戰力越高，工作站升級越快**；戰力達到 **7,000** 時係數歸零——**升級瞬間完成**。

| 編隊戰力 | 係數 | 9→10 級實際耗時（基礎 5,120 分）|
|:-------:|:----:|:---------------------------:|
| 0 | 1.00 | 5,120 分（約 3.6 天）|
| 1,750 | 0.75 | 3,840 分（約 2.7 天）|
| 3,500 | 0.50 | 2,560 分（約 1.8 天）|
| 5,250 | 0.25 | 1,280 分（約 21 小時）|
| ≥ 7,000 | 0.00 | **瞬間完成** |

**所以先練戰力，再衝工作站**。低戰力硬蓋工作站是在浪費時間——同一座站，7,000 戰力的人升級不用等，2,000 戰力的人要等好幾天。

> ⚠️ 反過來說，這也代表**工作站不是新手該優先投入的系統**。先把隊伍練起來（見 ⚡ 戰力與養成篇），戰力上去之後再回頭經營工作站，效率天差地遠。

## 4. 角色拜訪

部分角色在特定城市有專屬的**拜訪地點**。進入該城後可以用該角色觸發劇情，通常會提升**羈絆等級（relation level）**。

拜訪與探索地點的兩種解鎖條件：

| 條件類型 | 意思 |
|---------|------|
| `Actor` | 需要**持有指定角色**才能進入 |
| `SitePlot` | 需要**先把同城的另一個地點升到指定等級** |

也就是說，城內地點之間有**前置鏈**——某些地點要先解鎖別的地點才會開。

### 羈絆等級的效果

**每升一等羈絆，該角色的等級上限 +5。**

搭配 ⚡ 戰力與養成篇 的上限階梯來看：滿等 SSR 是 300 等，羈絆上限 2 就能推到 **310 等**；亨利羈絆上限 4，可以推到 **320 等**——這是目前全遊戲唯一能突破 300 的途徑。

**羈絆素材目前只有兩種**：

| 素材 | 來源 |
|------|------|
| 百盒 | — |
| 話術 | **性產業工作站**（全圖 152 個點位）|

這也解釋了為什麼「話術」不在職業經驗素材表裡——**它是羈絆專用素材**。想拉羈絆就得經營性產業工作站，兩個系統是綁在一起的。

## 5. 新手該怎麼做

**順序很重要**——工作站的升級時間跟你的編隊戰力綁在一起，戰力沒到位就衝工作站是在浪費時間。

1. **先把戰力練起來**。編隊戰力 7,000 是工作站升級的免等門檻；就算到不了，戰力每高一點升級都更快。**這一步優先於下面所有事**（見 ⚡ 戰力與養成篇）。
2. **搶冷門城的榜首**。中位數只要 16 點就能上榜，回報是**所有編隊戰力 +200**，而且吃國策加成——投報率遠高於任何其他行動，而且不受戰力限制，隨時可以做。
3. **挑點位多的城市蓋站**。全圖近半數城市只有 1 個點位，但有 26 座城有 6~8 個。帳號上限 20 座工作站，位置要挑過。
4. **同國工作站升級打八折**，優先蓋在本陣營主權範圍內。
5. **順路做，不要專程跑**。刷地路線經過的城市順手進去，別為了滲透額外耗體力。
6. **角色拜訪帶著走**。有拜訪地點的角色編進隊伍，經過對應城市時觸發；羈絆每升一等等級上限 +5，是唯一能突破 300 等的途徑。

> 🎯 **一句話總結**：滲透系統的兩個真正價值是**榜首的 +200 戰力**與**滲透比例抵銷距離衰減**（讓遠城變得可打）。工作站的素材產出反而是次要的——它的升級速度取決於你的戰力，所以本質上是「戰力高了之後才划算」的後期系統。
