🔐 帳號登入
⚠️ 重要安全警告：
  • 本功能需要您輸入遊戲帳號密碼，存在以下風險：
  • 帳號安全風險：在第三方網站輸入密碼可能導致帳號被盜
  • 隱私風險：您的遊戲資料將在瀏覽器中處理
  • ToS 風險：使用非官方工具可能違反遊戲服務條款
  • 本網站不會儲存您的密碼，但請自行評估風險
  • 如有疑慮，請使用「示範模式」查看範例資料
📌 技術說明： 由於瀏覽器安全限制 (CORS)，直接從網頁連接遊戲伺服器可能會失敗。 如果連接失敗，您可以：
  • 使用「示範模式」查看功能展示
  • 透過瀏覽器開發者工具直接測試 API
  • 使用本地代理伺服器繞過 CORS 限制
